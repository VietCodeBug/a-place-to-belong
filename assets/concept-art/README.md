# Forest Post Café — Concept Art

This folder is reserved for **original, approved PNG concept art**. No finished artwork has been produced or published yet.

The six required filenames, exact dimensions, standalone scene briefs, and consistency checks are defined in [the artwork production brief](../../docs/art-prompts.md).

Do not use unrelated stock images or the reference images supplied with the project brief as if they were original concept art. Once valid assets exist, add them here and update the top-level README gallery to point only at committed files.
