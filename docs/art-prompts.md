# Forest Post Café — Original Concept Art Production Briefs

**Current state:** These six image briefs are ready for production. **No original generated artwork has yet been committed.** The image-generation service tested during initialization rejected generation because it requires a paid basic plan or higher.

## How to use these briefs
Use the **shared art lock** at the start of every prompt. Generate each scene independently, but reuse an approved café exterior as an image reference when the available tool supports reference images. Do not claim the uploaded reference mood images are original project assets. Output native PNG files with actual pixels, inspect them, and resize/crop carefully if a generator does not support the exact requested dimensions.

### Shared art lock — prefix every prompt
> Original premium PC indie game concept art for Forest Post Café. Classic low-poly stylized 3D, deliberately faceted flat-shaded polygon geometry, simple clear silhouette design, cohesive miniature diorama look, matte diffuse colors, warm cinematic sunlight with soft shadows and gentle atmosphere. Charming forest woodland world with recognizable tiered polygonal pine trees. Architecture canon: small honey-oak timber café and post office, steep mossy sage-green gable roof with terracotta ridge detailing, muted teal window trim, cream plaster accents, mustard-yellow entrance door, warm wood porch, iconic wooden mailbox. Vehicle canon: compact vintage coral-red postal bicycle with thick tires and wicker mail basket. Palette: forest #496B59, sage #8BA58A, honey oak #B88254, terracotta #C87760, warm cream #F6E8D0, lake teal #8DC9CB, postal coral #C85E55. Spatially believable same-world architecture and props. No photorealism, no high-frequency PBR detail, no anime, no pixel art, no painted linework, no legible lettering, no captions, no logos, no watermarks, no interface, no heavy bloom.

## Publishing checklist
1. Generate original images using these briefs; do not pass off the four user-provided mood references as generated output.
2. Review for coherent building, bike and palette across the six scenes.
3. Convert each approved output to true RGB or RGBA **PNG** and size to the exact pixels above.
4. Reopen each PNG to verify decode, color and dimensions.
5. Place images at `assets/concept-art/<filename>` with the exact filenames listed.
6. Only after all referenced files are committed, replace the README’s prompt-gallery table with the actual relative Markdown image gallery.
7. Keep provenance notes (model, generation date, prompt revisions) with the project documentation.

**Visual references vs. original assets:** Images supplied in the kickoff are style references, not files to publish as newly generated artwork.
